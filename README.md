# 📡 Ranger Radio

A small experimental lab for learning software-defined radio, RF, antennas, signal processing, and radio-adjacent software development.

## Station

First receiver arriving **12Sep26**:

- **NooElec NESDR SMArt v5**
- HF / VHF / UHF receive capability
- NooElec stock antenna kit
- SDR++ on Windows
- Linux ThinkPad for portable/field experiments

Future plans include a Raspberry Pi-based listening node.

## What I'm Learning

- SDR fundamentals
- spectrum and waterfall analysis
- modulation and demodulation
- HF propagation
- improvised receive antennas
- antenna orientation, geometry, and placement
- RF noise and interference
- digital signal processing
- SDR + web/software development

## Field Journal

Experiments live in `/field_notes`.

The general method:

**predict → build → observe → record → change one variable → repeat**

Initial experiments will establish a baseline using the stock antennas before moving into improvised HF wire antennas.

## Software Projects

Eventually Ranger Radio may include:

- RF observation/logging tools
- antenna experiment database
- spectrum visualizations
- Node/JavaScript SDR utilities
- Morse/CW experiments
- Raspberry Pi receiver services
- mapping and ATAK/CoT experiments using benign data

## Scope

This is a personal learning project focused on lawful reception, amateur radio, public/benign signals, antenna experimentation, and software development.
